WEEK 9: FUNCTIONS OF SEVERAL VARIABLES

1. What is a Function of Several Variables?

In single-variable calculus you had f(x) — one input, one output. Now we upgrade to f(x, y) — TWO inputs, one output.

FORMAL DEFINITION:

A function z = f(x, y) maps each ordered pair (x, y) from a domain D in the real plane R2 to a unique real number z.

Domain: All valid input pairs (x, y)

Range: All possible output values z

Real-Life Analogy:

Pizza Cost: C = f(s, t) where s = size, t = toppings.

2. Increasing & Decreasing Functions

KEY RULE:
  • f is INCREASING in x: as x goes up, f goes up (while y stays fixed)
  • f is DECREASING in x: as x goes up, f goes down (while y stays fixed)
  • Test EACH variable separately — hold the other constant!

Solved Example — Airline Revenue

R = f(x, y) = 350x + 200y

x = number of full-price tickets | y = number of discounted tickets

Increase x → R increases. So INCREASING in x. Increase y → R increases. So INCREASING in y.

Solved Example — Car Rental

Formula: C = f(x, y) = 40x + 0.15y where x = days, y = miles driven

3. Comparative vs. Complementary Goods

SUBSTITUTE GOODS

When price of one goes UP, demand for the OTHER goes UP

Example: Coffee & Tea

OWN-PRICE EFFECT

When price of good goes UP, its OWN demand goes DOWN

Example: Coffee price

WEEK 10: COMPUTING PARTIAL DERIVATIVES ALGEBRAICALLY

1. The Golden Rule of Partial Derivatives

When finding fx: Treat y as a CONSTANT.

When finding fy: Treat x as a CONSTANT.

2. Notation You Must Know

NotationMeaningHow to Read
fx(x, y)Partial of f w.r.t. xf sub x
fy(x, y)Partial of f w.r.t. yf sub y

3. Basic Rules Review

  • Rule 1 — Constant: d/dx (c) = 0
  • Rule 2 — Constant multiply: d/dx (c x^n) = c * n x^(n-1)
  • Rule 3 — Power rule: d/dx (x^n) = n x^(n-1)

4. Full Worked Examples with Steps

EXAMPLE A — Simple Polynomial: f(x, y) = x^2 + 5y^2

fx = 2x

fy = 10y

EXAMPLE B — Mixed Term: f(x, y) = x^3*y^4

fx: 3x^2 * y^4
fy: 4x^3 * y^3

EXAMPLE C — Log & Exponential: f = e^x * ln(y)

fx: e^x * ln(y)
fy: e^x * (1/y)

EXAMPLE D — Function to a Power: f = (xy^2 + 1)^4

fy = 8 x y (xy^2 + 1)^3

EXAMPLE E — Quotient: g = xy / (x^2 + y^2)

gx = (y^3 - x^2 y) / (x^2 + y^2)^2

EXAMPLE F — Trig Functions: f(x, y) = cos(3x - 5y)

fx = -3 sin(3x - 5y)
fy = 5 sin(3x - 5y)

5. Three Variable Functions

  • When finding fx: treat BOTH y and z as constants
  • Compute ALL three partial derivatives if asked

6. Evaluating Partial Derivatives at a Point

Differentiate first, THEN substitute the point values.

Example: fy(1,3) for f = e^(x^2 + y^2) → fy = e^(x^2+y^2) * 2y → fy(1,3) = 6 e^10

PRACTICE QUESTIONS — Try These First, Then Check Answers

Q1. A hotel charges $80 per night per room and $5 per extra person. Write C = f(r, p) and find f(3,4).

Answer: C = 80r + 5p → f(3,4) = 260
